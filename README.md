🎥 NXTWATCH – Video Streaming Application (React.js)

A YouTube-style video platform with Login Authentication, Saved Videos, Dark/Light Theme, and Protected Routes — built using React.js and Context API.

🚀 Features

🔐 JWT Authentication

🔒 Protected Routes

🔎 Search Videos by Title

👍 Save/Unsave Videos

🌓 Dark / Light Theme Support

🗂️ Trending, Gaming, and Saved Videos sections

🎬 Video Item Details Page

⚛️ Global State using Context API

🌐 Real API Integration

📱 Fully Responsive UI
